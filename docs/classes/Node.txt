Basic_Node<typeName T>
    A basic building block for various data structures. It stores a single piece of data and provides methods to access and modify that data.

Template Parameter
T - The type of data stored in the node.

Attributes
# data: T - The data stored in the node.

Methods
+ data(): T - Returns the data stored in the node.
    Return - The data stored in the node.
+ set(value: T): void - Sets the data stored in the node to the provided value.
    Parameter - value: The value to set the data to.

Operators
+ operator= (value: T): Basic_Node<T> - Assigns a value to the data stored in this node.
    Parameter - value: The value to assign to the data.
    Return - A reference to this node after assignment.
+ operator== (other: Basic_Node<T>): bool - Compare the data stored in a node with the data stored in the other node.
    Parameter - other: The other node to compare with.
    Return - True if the nodes' data are equal, false otherwise.
+ operator!= (other: Basic_Node<T>): bool - Compare the data stored in a node with the data stored in the other node for inequality.
    Parameter - other: The other node to compare with.
    Return - True if the nodes' data are not equal, false otherwise.

# balance_factor: int - The balance factor of the node, used for balancing purposes. Negative values indicate a left-heavy tree, positive values indicate a right-heavy tree, and zero indicates a balanced tree.

Methods
# check_balance(): void - Checks the balance of the node and updates the height and balance factor accordingly. Called after the addition or removal of nodes.
    Note - This method is typically called after modifying the tree structure to ensure that the node remains balanced.
# rebalance(): void - Rebalances the node if it is unbalanced, adjusting pointers to maintain the properties of the balanced tree. This method is called if check_balance() detects an imbalance.
    Note - This method is typically called after check_balance() detects an imbalance.
# rotate_left(): Basic_Node<T> - Performs a left rotation on the node to balance the tree.
    Return - A pointer to the new root of the subtree after the left rotation.
# rotate_right(): Basic_Node<T> - Performs a right rotation on the node to balance the tree.
    Return - A pointer to the new root of the subtree after the right rotation.
# check_height(): void - Checks the height of the node and updates it based on the heights of its children.
+ get_height(): int - Returns the height of the node.
    Return - The height of the node in the tree.
+ get_balance_factor(): int - Returns the balance factor of the node.
    Return - The balance factor of the node.

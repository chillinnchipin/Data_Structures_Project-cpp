Linked List <typename T>
================
A doubly linked list is a data structure that is a list of linear nodes, where each node contains a value and pointers to the next and previous nodes in the list.

Template Parameter
T - The type of data stored in the linked list.

Attributes
# head: Linear_Node<T> - Pointer to the first node in the linked list.
# tail: Linear_Node<T> - Pointer to the last node in the linked list.
# size: int - The number of nodes in the linked list.

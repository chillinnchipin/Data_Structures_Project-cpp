# Search Algorithms
linear_search<typeName T>(target: T, data: T[], int size): int - searches for the location of target in list data using linear search and returns the index if found
    Param target - the target to search for
    Param data - the list of items to search for the target in
    Param size - the size of data
    Return - the index of the target or -1 if target not found
    Note - target and data must have the same type T.
binary_search<typeName T>(target: T, data: T[], int size): int - searches for the location of target in list data using binary search and returns the index if found
    Param target - the target to search for
    Param data - the list of items to search for the target in
    Param size - the size of data
    Return - the index of the target or -1 if target not found
    Note - target and data must have the same type T.
fibonacci_search<typeName T>(target: T, data: T[], int size): int - searches for the location of target in list data using fibonacci search and returns the index if found
    Param target - the target to search for
    Param data - the list of items to search for the target in
    Param size - the size of data
    Return - the index of the target or -1 if target not found
    Note - target and data must have the same type T.

# Sort Algorithm
selection_sort<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data
bubble_sort<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data
insertion_sort<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data
quick_sort<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data
merge_sort_recursive<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data
merge_sort_threaded<typeName T>(data: T[], int size): T[] - sorts the list data using selection sort and returns a sorted list
    Param data - the list to sort
    Param size - the size of the list
    Return - a sorted copy of data

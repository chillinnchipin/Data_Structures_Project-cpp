# C++ Node & Data Structures Library
A library of data structures and algorithms in c++ for pactice creating data structure and for useage in future projects.

## Installation
There currently is no working executable for this project.
Download the repo from github to use.
```bash
    git clone https://github.com/chillinnchipin/cpp_node
```

## Roadmap
### Algorithms
- List search algorithms
- List sort algorithms
- graph search algorithms
### Data Structures
- Linked List
- LIFO and FIFO List (Stacks and Queues)
- Trees
    - Binary Search Tree
    - AVL Tree
    - Red Black Tree
- Heaps
### Testing
- Unit test for all data structures and algorithms
### Benchmark Testing
- Executable that test the time and memory complexity of each algorithm
### Package installation
- Library accessable through a single include command
- apt package for easy installation of library and testing code
